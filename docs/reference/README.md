projects, used as research input for Ingenious Forge. The pages quote and
paraphrase each project's source. That material belongs to its authors and
is not covered by Forge's Apache 2.0 license: each folder keeps the
project's own `LICENSE`, plus its `NOTICE` where the project provides one.

## Adding a project

When you add a folder with `scripts/generate-docs.mjs`, also copy the
project's `LICENSE` (and `NOTICE`, if it has one) into the folder and add a
row above. Do not add projects without an open-source license.
