## 3. Playwright end-to-end UI suite

### Native Claude transcript parity

`tests/e2e_ui/messages/test_native_claude_render_parity.py` tests the native `claude-native` session experience across the terminal and chat views. Its module documentation describes the key data flow: the native Claude CLI runs in the session terminal, the SPA’s Terminal view attaches to that TUI over a WebSocket, and the SPA’s Chat view renders the canonical transcript returned by `GET /v1/sessions/{id}/items`. A native bridge carries messages from the web composer into the Claude process and forwards Claude’s transcript back as conversation items. [tests/e2e_ui/messages/test_native_claude_render_parity.py:1-10]()

The journey uses an in-process mock LLM server rather than a live Anthropic endpoint. The module documentation says the `native_claude_mock_session` fixture writes a mock `anthropic` provider configuration and redirects the runner’s `ANTHROPIC_BASE_URL` to the mock server; each tested turn installs its expected token as a fallback response. [tests/e2e_ui/messages/test_native_claude_render_parity.py:12-17]()

The test is marked `nightly` and has a 300-second timeout. It opens the session URL, switches to Terminal view, waits for the terminal to report `data-state="connected"`, then returns to Chat view. It generates unique markers for user and assistant turns and installs fallback responses before sending composer prompts. [tests/e2e_ui/messages/test_native_claude_render_parity.py:117-142]() [tests/e2e_ui/messages/test_native_claude_render_parity.py:146-161]()

The helper `_type_into_tui` focuses xterm.js’s hidden `.xterm-helper-textarea`, types the prompt, and presses Enter. The test uses this terminal input path for a TUI-originated turn, complementing composer-originated turns. The module documentation states that another journey exercises web-composer delivery while the TUI composer is occupied by states such as history search, shell mode, or the rewind dialog. [tests/e2e_ui/messages/test_native_claude_render_parity.py:19-23]() [tests/e2e_ui/messages/test_native_claude_render_parity.py:64-68]() [tests/e2e_ui/messages/test_native_claude_render_parity.py:104-115]()
