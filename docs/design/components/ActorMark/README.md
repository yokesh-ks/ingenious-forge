# ActorMark

Shows who acted: a square punch for an agent, a round mark for a person.

**Consumer provides:** `name`, `kind`, and optionally `role`, `showName` and `code` to override the letters.

- Give each agent one fixed three-letter `code`, the same one its `Hallmark` uses.
- Never use a round mark for an agent or a photo in a punch.
- Name agents by role, not as characters.
