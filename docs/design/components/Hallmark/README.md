# Hallmark

The signature mark of the system: maker, assay result and date, struck in one strip.

**Consumer provides:** `maker` (three letters), `state`, `date`, and `href` to the evidence.

- Put one beside every accepted result: a merged change, a closed book, a filled order.
- Link to the evidence whenever it exists.
- Use `unproved`, dashed, rather than leaving the mark off.
