# Logo

The Ingenious Clan mark, alone or with the name, drawn live so it follows the theme.

**Consumer provides:** optional `variant` (`mark` or `lockup`), `size` (the mark's height in px) and `tone` (`reversed` on `iron` and other fixed dark grounds).

- Keep one tile of clear space around it.
- Do not set the mark below 16px.
- Use the lockup where the name is not already on screen.
