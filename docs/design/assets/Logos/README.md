# Logos

No tagline belongs in a logo file. Each file below has fixed colours, because an image cannot inherit them.

- `clan-mark.svg`: `ink` tiles and a `gate` disc, for light grounds.
- `clan-mark-reversed.svg`: `on-iron` tiles and a brass disc, for dark grounds.
- `clan-mark-ink.svg`: all `ink`, for single-colour use on light grounds.
- `clan-mark-white.svg`: all white, for single-colour use on dark grounds.
- `clan-app-icon.svg`: the reversed mark on `iron`, for favicons and app icons.
- `clan-lockup.png`: mark and name for light grounds.
- `clan-lockup-reversed.png`: mark and name for dark grounds.
